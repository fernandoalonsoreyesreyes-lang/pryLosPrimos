# pryLosPrimos - Sistema de Tienda LOS PRIMOS

Proyecto académico desarrollado en Java con Maven para la materia de Estructura y Organización de Datos.

Simula la gestión de una tienda de abarrotes llamada "LOS PRIMOS" que necesita controlar su inventario de productos de forma digital.

### 🎯 Objetivo del Sistema
Reemplazar el control manual en libreta por un sistema que permita manipular un arreglo de productos de manera eficiente.

### ⚙️ Funcionalidades Principales
El sistema realiza operaciones CRUD sobre el arreglo de productos:

*   **Agregar Producto:** Registra un nuevo producto con Código, Nombre, Precio e Ingredientes.
*   **Listar Productos:** Muestra todos los productos existentes en el inventario.
*   **Editar Producto:** Permite modificar los datos de un producto existente por su código.
*   **Eliminar Producto:** Borra un producto del arreglo.
*   **Reportes:** Genera reportes filtrando por precio y búsqueda por código.

### 🛠️ Tecnologías Utilizadas
*   Lenguaje: Java
*   Gestor de proyectos: Maven
*   IDE: NetBeans / IntelliJ IDEA
*   Paradigma: Programación Orientada a Objetos

### 📁 Estructura del Proyecto
